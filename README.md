# Nancy Games — GitHub Pages Website

Static website for `nancygames.space`. Includes Home, About Us, Privacy Policy, and Contact Us.

## Publish
1. Create a public GitHub repository (e.g. `nancygames-website`).
2. Extract the ZIP and upload the **contents**, not the ZIP, to the repository root.
3. Settings → Pages → Deploy from a branch → `main` / `(root)`.
4. Confirm custom domain `nancygames.space` in Settings → Pages (a CNAME file is included).
5. Before switching DNS at Hostinger, record existing DNS settings and ensure Hostinger email MX/SPF/DKIM remain untouched.
6. Configure apex A records to GitHub Pages and `www` CNAME to `<github-username>.github.io` if desired.
7. Wait for DNS verification, enable HTTPS, and test all pages.

**Note:** The privacy policy is a website-only starting point. Review and adapt it before publishing, and create separate policies for apps as appropriate.
